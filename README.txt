Bicalho & Partners - Projeto organizado para VSCode

Estrutura:
- index.html: página inicial
- css/: estilos separados
- js/: scripts e animações
- images/: imagens, logo e foto do Filipe
- pages/: páginas internas, incluindo páginas individuais dos serviços
- components/: trechos reutilizáveis de navbar, footer e cards

Como editar:
1. Abra esta pasta no VSCode.
2. Para mudar textos da home, edite index.html.
3. Para mudar estilos, edite css/style.css.
4. Para mudar páginas de serviços, edite os arquivos dentro de pages/.
5. Para publicar, compacte esta pasta e envie no projeto correto da Netlify.
